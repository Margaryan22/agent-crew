# Claude Code does the AI work

Agent Crew is a team of AI agents packaged as a plugin for **Claude Code**, Anthropic's official coding assistant. The agents run inside Claude Code, so:

- they use **your own Claude subscription** (Pro or Max) — or an API key if that is how you sign in to Claude Code;
- your sign-in stays with Claude Code; Agent Crew never sees credentials and never calls a model itself;
- everything the crew does is visible in the Claude Code chat, where you can stop or redirect it.

After **Install Claude Code**, open its panel (the Claude icon in the sidebar) and sign in.
