# Your first project

1. **Open an empty folder** (File → Open Folder…).
2. **New Project** — describe the tool in a sentence or two, in any language, e.g. *"Online booking for a barbershop: clients choose a barber and a free slot, the owner sees the day's schedule and weekly revenue."*
3. Claude Code opens with `/agent-crew:new-project …` in its input box — **press Enter**.
4. **Answer the interview** — a few multiple-choice questions about users, data and reports.
5. The crew writes and reviews a brief, designs the architecture, writes acceptance tests, then builds task by task with QA and security review.

While it works, the **Agent Crew** view shows the phase, the task board, questions waiting for you (answer them right there) and the estimated spend. When it finishes, open **Report** for what was built and how to run it.
