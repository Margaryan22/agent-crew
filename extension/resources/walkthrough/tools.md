# Tools the generated project needs

The crew builds a **TanStack Start** web app (React, TypeScript) with **PostgreSQL** and end-to-end tests. On this machine you need:

| Tool | Why |
| --- | --- |
| Node.js 22 or newer | runs the app, its tests and the crew's helper CLI |
| git | the crew commits each task separately |
| Docker (Docker Desktop, OrbStack…) | the local PostgreSQL database |

**Check Setup** runs the checks and lists anything missing.
