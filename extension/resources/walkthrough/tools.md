# Tools the generated project needs

The crew picks the stack for your idea and, by default, an embedded database, so very little has to be installed. On this machine you need:

| Tool | Why |
| --- | --- |
| Node.js 22 or newer | runs the app, its tests and the crew's helper CLI |
| git | the crew commits each task separately |
| Docker (optional) | only for the TanStack preset or a project that needs a database server |

**Check Setup** runs the checks and lists anything missing.
