# Your first project

**Start Demo Project** asks the crew to build a small habit tracker:

> A tiny habit tracker web app: people add daily habits, tick them off each day and see a 7-day streak for each habit.

Then watch:

- **Chat** — each agent's messages, tool calls and status, plus escalations with answer buttons.
- **Tasks** — the board from `.crew/tasks/`, grouped by status and updated live. Right-click a task for **Show Diff**.
- **Decisions** — architecture decision records from `.crew/decisions/`.
- **Status bar** — money spent against the cap and the agent currently working.

Use your own idea with **Crew: New Project**, add to an existing project with **Crew: Feature**, and stop any time with **Crew: Stop** (resume later with **Crew: Resume**).
